# Website maintenance

The public project site is https://chat-refinedtpp.com/. It is a static introduction/documentation and promotional site; it does not host the analysis backend. The local application opens separately at http://127.0.0.1:8000 after an authorized package is installed.

## Current layout and preview

The website remains at root `index.html`, with demonstration media under `assets/videos/`. Its HTML, CSS and JavaScript can be previewed from the repository root with Python installed:

```sh
python -m http.server 8080
```

Open http://localhost:8080. This command serves static files for development; it does not start the analysis platform. Stop the preview when done. Run it only in the public website checkout, not in a directory containing private packages or credentials.

## Deployment and review

Cloudflare Pages deploys the production `main` branch. Use a focused branch and pull request, inspect the Pages preview when available and verify changed links and behavior. Wait for Codex bot to finish reviewing the latest commit, address findings, and obtain explicit maintainer authorization before merging. An AI review summary is distinct from GitHub Approve.

For site changes, check keyboard access and narrow-screen layout. For video changes, check load, playback, seeking and pause on dialog close. Preserve media policies, attribution and credits.
