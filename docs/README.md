## Documentation maintenance

Update the root README, version notes, installation guide and website availability information together when a version is publicly distributed. Future release notes must link to the actual application asset and checksum; GitHub's autogenerated repository source archive currently contains only the public repository files.

Approved real example datasets will have a separate provenance and permissions record. No real dataset is published by this documentation change. Their future location and publication requirements are described in the repository plan.
