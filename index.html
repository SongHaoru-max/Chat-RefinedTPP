Quick Start

  1. Install the Python version required by your release.
  2. Unpack the release and run the setup script.
  3. Start the local app. Model configuration is optional for scientific analysis.
  4. Describe the design, upload the required files, review the plan and confirm the run.

Developer Guide

The local backend supplies scoped Agent instructions and validated tools. Approved runs use fixed analysis code; reports read the resulting files and run metadata.

The published guide will link to source entry points for the Agent, execution, and reports.
