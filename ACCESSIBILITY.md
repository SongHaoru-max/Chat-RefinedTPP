# Accessibility

Chat-RefinedTPP aims to make its public website and documentation usable with keyboard navigation, readable text, clear focus states and assistive technologies.

## Current scope

This statement covers the public static website and its demonstration video. It does not establish an accessibility assessment of the separately distributed local analysis application.

The website includes responsive layouts, visible focus styling, native video controls and a reduced-motion preference for smooth scrolling. A full accessibility audit has not been completed, and conformance with a particular accessibility standard has not been certified.

## Known limitations

The current 89-second promotional video has no dedicated caption track or accompanying transcript. Browser, operating system and assistive technology combinations have not all been tested.

The public statistics charts currently contain explicitly labelled illustrative data. Their textual descriptions and legends should remain available when the charts change.

## Report a barrier

Use the feature request form for an accessibility improvement or the bug report form for broken behavior. Include the affected page, the task you were attempting, the browser and device, and the assistive technology if relevant and you wish to share it.

Screenshots or reproduction steps are helpful when safe to publish. Omit personal data, credentials and unpublished research material. Chinese and English feedback are welcome.
