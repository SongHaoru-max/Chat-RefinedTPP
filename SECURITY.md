# Security Policy

## Scope

Security reports are welcome for the public Chat-RefinedTPP website, its published repository files and deployment behavior.

The analysis application source and installation packages are not currently distributed through this repository. Reports involving a separately obtained build should identify its version and source so the maintainer can establish the affected scope. No supported-version schedule has been published.

## Report a vulnerability privately

On this repository, open **Security → Advisories → Report a vulnerability** when GitHub's private vulnerability reporting is available.

If the private reporting button is unavailable, open a public issue requesting a private security contact channel. Include no vulnerability details, exploit steps or sensitive attachments in that issue. Wait for a private channel before sharing the report. A dedicated security email address has not yet been published.

For ordinary functional bugs without a security impact, use the public bug report form.

## Useful report details

Share the following only through the private reporting channel.

- Affected URL, file or software version.
- Observed behavior, expected behavior and the potential impact.
- Minimal reproduction steps using synthetic data.
- Redacted diagnostics and any relevant timestamps.
- Any mitigation you have identified.

Use only accounts and data you control or have permission to test. Keep credentials, personal data and unpublished experiments out of reports and public discussions.

## Handling reports

The maintainer will assess scope, reproduce the issue where possible, coordinate a fix and agree on appropriate disclosure with the reporter. Response and remediation depend on severity and available resources. No fixed response time or bounty program is currently offered.
