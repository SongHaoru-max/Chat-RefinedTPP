The MIT grant covers the original website code and documentation to the extent the maintainer holds the relevant rights. Logo image data embedded in `index.html` remains subject to the logo policy. The video keeps its separate terms when downloaded or copied with the repository.

The current website license does not preselect a license for future platform-source or binary releases. A complete platform dependency inventory, including LangGraph, figures4papers, assistant-ui and thinking-orbs, will be finalized before those releases.

## Permission requests

Use a repository issue to request permission to reuse the project logo or video. Identify the material and proposed use. If the request contains sensitive details, request a private contact channel first.

Upstream terms continue to govern third-party material. The maintainer can grant permission only for rights they hold or are authorized to grant.
