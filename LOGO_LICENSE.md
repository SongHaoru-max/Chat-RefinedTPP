This policy covers the Chat-RefinedTPP logo, brand artwork and logo image data embedded in website source files.

Public viewing of the logo as part of the project website and linking to that website are welcome.

Request permission through a repository issue describing the intended use. A sensitive request can first ask for a private contact channel.
