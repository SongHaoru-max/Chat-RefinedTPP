# Code of Conduct

This project welcomes respectful participation across backgrounds, experience levels and scientific disciplines.

## Expected conduct

- Discuss ideas and evidence with care, and critique work constructively.
- Respect people's privacy, names and boundaries.
- State uncertainties and acknowledge corrections.
- Keep discussions relevant to the project.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation and publishing someone's private information without permission are unacceptable.

## Scope and moderation

This code applies to project issues, pull requests, reviews and other spaces managed by the maintainer.

Haoru Song (宋昊儒) maintains these spaces and may edit or remove harmful content, close disruptive discussions, restrict participation or block repeat offenders. Moderation should consider the context and severity of the behavior and explain decisions where appropriate without exposing private information.

## Reporting

For a moderation request that is safe to discuss publicly, open an issue with a brief description and a link to the relevant content.

For a sensitive concern, open an issue requesting a confidential contact channel without posting names, allegations, screenshots or other private details. Wait for the maintainer to arrange that channel before sharing the report. A dedicated private conduct-reporting address has not yet been published.

Content that violates GitHub's platform policies can also be reported through GitHub's Report abuse controls. Suspected software vulnerabilities follow [SECURITY.md](SECURITY.md).
